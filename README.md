# Arysson — Back-end

Portfólio de Arysson Menezes. React, Vite, Tailwind e Framer Motion.

No ar: https://arysson5.github.io/Meuportifolio/

## Rodar

```bash
npm install
npm run dev     # desenvolvimento
npm test        # testes
npm run build   # gera dist/
```

Cada push na `main` roda os testes, gera o build e publica no GitHub Pages (`.github/workflows/deploy.yml`).

Textos em `src/data/site.ts`, stack em `src/data/stack.ts`, regras de conteúdo em `CONTRATO.md`.
